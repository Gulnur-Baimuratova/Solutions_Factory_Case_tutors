# Тестовое задание: бизнес-аналитик + project manager

**Цифровой помощник тьютора с AI-анализом наблюдений за детьми**
Заказчик: Сбер · Конечный клиент: «Академия маленьких наук» (ИП Воронина Ю. А.), центр развития детей, Москва

В репозитории выполненное тестовое задание на роль BA + Project Manager: записка о данных, ИИ-анализе и защите данных, вопросы к стейкхолдерам, бизнес-процесс со схемами, дорожная карта пилота и план коммуникаций. Отдельно приложен **кликабельный HTTP-прототип** мобильного интерфейса для четырёх ролей.

---

## Суть задачи

Тьюторы ежедневно наблюдают за детьми с ОВЗ (эмоции, коммуникация, поведение, питание, сон, сенсорика), но записи разрознены: Excel, заметки, устные отчёты. Динамику и повторяющиеся связи трудно увидеть, у родителей нет наглядной картины, врачи не получают систематизированных данных.

Решение — единая карточка наблюдения и профиль ребёнка. **Светофор** сравнивает каждый день с личной нормой ребёнка за 28 дней. **Связи «фактор → исход»** ищет статистика с порогами, GigaChat формулирует вывод простым языком. Каждая подсказка показывает исходные наблюдения, решение принимает специалист. Доступ разграничен по ролям, требования 152-ФЗ к данным о здоровье ребёнка учтены.

Пример на условных данных: в дни, когда ребёнок спал меньше 8 часов, агрессия была в 10 из 14 дней (71%), в остальные дни — в 7 из 46 (15%). Это в 4,7 раза чаще.

## Кратко по блокам

**Данные и ИИ.** Карточка заполняется за 2 минуты, в основном выбором из вариантов. Каждая запись хранится с ID, автором и версией. Подсказка показывается, только если фактор встретился не меньше 8 раз, разница не меньше чем в 2 раза и связь повторяется на разных отрезках периода. ИИ не ставит диагнозы.

**Вопросы стейкхолдерам.** Сначала ЛПР, метрики и данные пилота по 9 детям, согласия и контур GigaChat. Затем работа тьюторов, методики, сигналы риска, ожидания родителей и врачей, архитектура MVP.

**Бизнес-процесс.** Путь от утренней отметки сна родителем до решения специалиста по AI-подсказке. В процессе есть предзаполнение, проверка противоречий, защита от дублей, версии и журнал доступа, уведомления о критических событиях.

**Дорожная карта.** Работаем от прототипа, UX-тест с тьюторами на второй неделе, проверка ИИ на данных пилота, неделя реального пилота с замером метрик. Ключевые риски: персональные данные детей и доверие к выводам ИИ.

## HTTP-прототип

`Прототип_Цифровой_помощник_тьютора.html` — самодостаточный файл без внешних зависимостей, работает офлайн. Сверху переключаются роли, в центре мобильный интерфейс, по бокам матрица доступа и журнал обращений к данным.

- **Тьютор:** список детей со светофором; карточка дня с предзаполненным сном, быстрыми кнопками эпизодов, проверкой противоречий и разбором комментария; после сохранения сразу пересчитываются светофор и графики.
- **Специалист:** AI-подсказки с раскрываемыми исходными наблюдениями, кнопки «принять / исправить / отклонить с причиной»; профиль, ИОМ и занятия; метрики пилота, включая долю принятых AI-выводов.
- **Родитель:** утренняя отметка сна, понятная динамика, только одобренные рекомендации и видео заданий.
- **Врач:** медицинская сводка без педагогических данных, дети без согласия на передачу данных недоступны, выгрузка к приёму.
- **Демо-сценарий:** наблюдение → анализ → динамика → подсказка.

Ограничения прототипа: данные синтетические, имена условные. Светофор и связи считаются по правилам из записки, тексты, которые в продукте формулирует GigaChat, собраны по шаблону. Серверной части и авторизации нет.
